# Cruciverba
Cruciverba Interattivo 10x10


Questo progetto consiste nello sviluppo di un'applicazione desktop in Java che riproduce un cruciverba interattivo. L'applicazione utilizza la libreria grafica Swing per creare un'interfaccia utente intuitiva (GUI), composta da una griglia 10x10 di celle cliccabili e due pannelli laterali per la visualizzazione delle definizioni (Orizzontali e Verticali).

L'obiettivo è permettere all'utente di risolvere lo schema cliccando sulle caselle bianche, inserendo le lettere e ricevendo un feedback immediato sulla correttezza della risposta.
